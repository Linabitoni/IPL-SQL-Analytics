# IPL-SQL-Analytics
## Project Overview 
This project analyzes Indian Premier League (IPL) data using SQL to uncover insights about teams, players, venues, and match outcomes. 
## Dataset 
Source: Kaggle IPL Dataset 
## Tools Used 
- SQL
- MySQL
- GitHub 
## Analysis Performed 
- Top run scorers
- Team win percentage 
-Toss win vs match win analysis
- Venue-wise statistics
- Highest individual scores

- Dataset files
- SQL queries
- Screenshots of results
- Documentation
